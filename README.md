# EnergyCoffee – Energy Consumption Monitoring and Cost Estimation

My application is monitoring energy consumption and estimating electricity costs through an interactive dashboard, focuses on backend development, data persistence, business logic, and web application development using Java and Spring technologies.

## Features

- **Energy Consumption Tracking** – Record electricity consumption in kWh.
- **Cost Estimation** – Calculate estimated electricity costs based on recorded consumption.
- **Consumption Monitoring** – Compare consumption against configurable thresholds.
- **Dynamic Dashboard** – Display energy consumption information and estimated costs.
- **Data Persistence** – Store and retrieve energy consumption records.
- **External Data Integration Practice** – Explore communication with external services as part of backend development.

### Backend Architecture

- Java 21
- Spring Boot 3.4.0
- Spring Data JPA & Hibernate, Security
- REST API

### Frontend Architecture

- Thymeleaf
- HTML5
- CSS3
- JavaScript (Vanilla JS)


## Project Goals

EnergyCoffee is a practical backend development project focused on strengthening skills in:

- Java and Spring Boot application development
- REST and HTTP concepts
- Database integration with PostgreSQL
- Business logic implementation
- Automated testing
- External system communication
